# yume-interpolation-fix

Minecraft 26.3 で導入されたエンティティ補間方式を、以前の補間方式と切り替えられるようにする MOD です。

「設定」→「アクセシビリティ設定」に「エンティティ移動の補間方式」を追加します。

## 注意

この MOD はクライアントから見えるほかのエンティティ・プレイヤーの移動経路を変更します。  
バニラ (26.3) の挙動の変更およびヒットのしやすさの変化を引き起こすため、サーバー管理者からの許可が得られていない場合は広義のチートに該当します。  
多くのアンチチートは 26.3 クライアントでの挙動は 26.3 の補間方式で検査しているものと思われるので、検出されるおそれがあります。  
管理者からの明示的な許可があるサーバー以外では使用しないでください。  

## ビルド方法

```sh
./gradlew build
```

成果物は `build/libs/yume-interpolation-fix-1.0.0.jar` です。
